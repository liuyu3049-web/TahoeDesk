# GlassShell（Windows 仿 macOS 液态玻璃桌面环境）设计文档

- **日期**：2026-11-23
- **状态**：待最终确认（Ready for User Approval — Builder Check Completed）
- **目标平台**：Windows 11（已验证环境：Windows 11 Build 26200+，.NET 8 `net8.0-windows10.0.22621.0`）
- **暂定代号**：`GlassShell`（Designer Call，开源发布前可随时更名）

---

## 1. 背景与产品意图（Intent & Why）

本项目旨在打造一款运行在 Windows 11 上的高保真 **macOS Tahoe（26+）液态玻璃（Liquid Glass）** 桌面环境软件，覆盖顶部菜单栏、底部程序坞（Dock）、控制中心、聚焦搜索（Spotlight）与启动台（Launchpad）。

- **使用场景与演进路径**：作者先作为个人主力日常桌面环境深度打磨，达到稳定、丝滑、真像 macOS 的体验后，以开源项目形式发布到 GitHub。
- **核心产品哲学（反 Nexus 化）**：拒绝 Nexus 等美化软件那种堆砌上百个参数的风格。坚持 **Opinionated macOS-First** 原则——几何比例、连续圆角（Squircle）、间距、阴影、字体层级、高斯放大曲线与弹簧阻尼直接按 macOS 视觉标尺定死，开箱即高还原，仅保留 macOS 原生本身提供的极少数设置项。
- **核心差异化卖点**：**绝对静默、零闪烁的前台 Windows 应用菜单栏联动** + **阶段一即落地的真实 DXGI 液态玻璃光学折射质感**。

## 2. 目标、非目标与红线（Goals, Non-Goals, Anti-Goals）

### 2.1 目标（Goals）
1. **真·液态玻璃视觉还原**：贴近最新 macOS 26+ Liquid Glass 风格——默认通透无底条的顶部菜单栏（可选开启半透明底色）、悬浮 Squircle 液态玻璃胶囊 Dock（GPU 实时背景采样模糊 + 边缘光学折射 + 镜面高光描边 + 柔和多层外投影 + 悬停图标自由冲出胶囊上方）、卡片式控制中心、居中悬浮聚焦搜索与全屏模糊启动台。
2. **本土化品牌替换**：保留与 macOS 一致的外形和布局，将苹果品牌与术语替换为 Windows 元素（左上角替换为 **Win11 Logo**；访达 → **资源管理器 / 此电脑**；废纸篓 → **回收站**；快捷键提示按 Windows 规范显示 `Ctrl` / `Alt` / `Shift` / `Win`）。
3. **静默式前台应用菜单栏联动**：随前台窗口切换实时提取并显示目标应用菜单，严格不闪烁原窗口原生下拉菜单；支持静默提取的软件直接联动真实命令，不暴露静态菜单树的现代软件通过内置高精度 JSON 应用配置表与通用窗口菜单无缝补齐。
4. **安全隐藏 Windows 原生任务栏**：软件运行时自动隐藏 Windows 原生任务栏、拦截单按 `Win` 键改为呼出启动台、注册顶部工作区（AppBar）防止最大化窗口被顶栏遮挡；在正常退出、异常崩溃、强杀或系统注销时，**确保可靠恢复原生任务栏与屏幕工作区**。
5. **主力级日常可靠性**：标准用户权限运行（无 UAC 弹窗、支持绿色便携版、保留桌面/资源管理器向 Dock 拖拽能力），常驻内存控制在 **60–100 MB** 区间，60/120fps 流畅动效，全屏游戏/视频自动避让，**零侵入式 DLL 注入**（开源安全、不触发杀毒误报）。

### 2.2 非目标（Non-Goals — v1 明确不做）
- **不改造第三方窗口标题栏**：不向第三方进程注入红黄绿交通灯按钮或剥离其原有内置菜单栏。
- **不做万能主题/皮肤编辑器**：不支持任意边框色、像素微调、异形 Dock、繁杂特效开关。
- **不替换 `explorer.exe` 系统外壳**：运行于标准 Windows Shell 之上，保留桌面图标、文件对话框与组合快捷键完整性。
- **v1 不做高风险窗口合成器接管**：不实现台前调度（Stage Manager）、调度中心（Mission Control）虚拟桌面接管，不对第三方 HWND 做 `DWMWA_CLOAK` 伪最小化劫持或神灯扭曲变形。
- **v1 不在控制中心内重造完整系统设置**：Wi-Fi 密码连接面板、蓝牙配对向导、复杂剪贴板管理器均复用 Windows 原生界面，不重复造轮子。

### 2.3 红线（Anti-Goals — 出现即视为失败）
- 崩溃或强杀进程后，Windows 原生任务栏永久消失无法恢复。
- 点击顶栏菜单时，下方原软件窗口内突然弹出或闪烁一下它自己的原生下拉菜单。
- 读取前台应用菜单阻塞 UI 线程或拖慢前台软件（必须后台隔离 + 超时熔断）。
- 拦截 `Win` 键导致 `Win+E`、`Win+D`、`Win+L`、`Win+V`、`Win+Shift+S` 等组合热键失效。
- 全屏游戏或全屏视频时，顶部菜单栏或 Dock 遮挡画面不避让。
- 设置界面堆满密密麻麻的参数，或视觉呈现廉价生硬塑料感。

## 3. 技术约束与权限模型（Constraints）

1. **开发环境前提**：本机当前为 Windows 11 Build 26200，已安装 `.NET` 运行时与 `Node.js v24.16.0`，进入编码前需先安装 **.NET 8 SDK**（目标框架 `net8.0-windows10.0.22621.0`）。
2. **零 DLL 注入与公开 API 约束**：所有系统交互仅使用公开/标准的 Win32 API、COM（`IUIAutomation`）、DXGI / Direct3D 11、DWM API 与 WinRT API；禁止依赖易随 Windows 更新失效的未公开内核状态（如 WNF 内存写入）。
3. **权限与 UIPI 模型（Designer Call）**：
   - 默认以 **标准用户（Medium Integrity）** 运行，免 UAC 弹窗、完整支持从桌面/资源管理器拖拽文件或图标到 Dock，并支持无签名绿色便携发布。
   - 当前台焦点切至管理员权限（High Integrity）窗口（如任务管理器、管理员终端）时，Windows UIPI 会阻止普通进程发送命令；`MenuEngine` 优雅降级为只读/基础窗口信息展示，不抛异常、不卡死。
4. **焦点不抢占约束**：顶部菜单栏与底部 Dock 窗口均设置 `WS_EX_NOACTIVATE` + `WS_EX_TOOLWINDOW`，点击顶栏或 Dock 时不抢走目标应用前台焦点。

## 4. 技术方案选型（Approaches Considered）

在确定实现路线前，评估了 3 条真实可行的技术路线（排除了打包重/系统 API 弱的 Python 方案与从零手写全部控件的纯 C++ Win32 方案）：

| 方案 | 核心架构 | 主要优势 | 主要取舍 |
| :--- | :--- | :--- | :--- |
| **方案 1（已选定）** | **纯原生 C#（.NET 8 + WPF + WinRT/UIA + 轻量 DXGI/D3D11 液态玻璃着色器）** | 单一 C# 语言工程干净；原生多浮层窗口无跨边界裁切（多级菜单/气泡/IME 极稳）；同进程 UIA/Win32 菜单读取零 IPC 延迟；DXGI 局部采样直出真·液态玻璃折射与真 Squircle 胶囊；免 WinAppSDK 重型依赖、内存低（60–100 MB） | DXGI/D3D11 与 WPF 合成层的渲染封装在阶段一有一定工程量 |
| **方案 2** | C#（.NET 8）后台系统服务 + WebView2（React/TS）前端界面 | 前端样式与迭代快；GitHub 前端贡献门槛低 | 多实例 Chromium 内存高（150–250 MB+）；多级下拉菜单与气泡跨窗口裁切棘手；难做真实底层背景折射 |
| **方案 3** | C# + Direct3D 11 / DirectComposition + 全自绘 Skia UI 引擎 | 极致帧率与最低内存 | 缺乏现成控件与中文输入法/复杂文本布局支持，开发与维护成本倍增 |

**选定结论**：用户选定 **方案 1**，并明确选择在阶段一即通过 **轻量 DXGI 屏幕局部采样 + HLSL 液态玻璃着色器** 实现真实的 macOS Tahoe 液态玻璃质感（而非退化为普通 DWM 磨砂块）。

### 5.1 原生任务栏接管、托盘呼出与 `Win` 键拦截（`Shell`）

1. **原生任务栏隐藏与防弹回状态机**：
   - 启动时隐藏 `Shell_TrayWnd`（及多屏场景下仅作用于主屏或按策略处理），并注册顶部 **28 DIP** 高度的 `SHAppBarMessage` 工作区，确保最大化窗口顶边恰好贴齐菜单栏下沿。
   - 监听 `TaskbarCreated`（处理 `explorer.exe` 重启）及 `EVENT_OBJECT_SHOW`（监控 `Shell_TrayWnd`）：非用户主动“临时查看托盘”状态下，若系统通知等事件导致原生任务栏试图重新显示，自动将其重新隐藏，防止盖住 Dock。
2. **第三方系统托盘临时呼出（用户已确认）**：
   - 顶栏右侧提供一个低调的托盘展开按钮（如小折叠箭头）。点击后：GlassShell **平滑收起底部 Dock** 并临时取消隐藏屏幕底部的原生任务栏（同时聚焦系统托盘区域），方便用户点击微信、代理工具等第三方托盘图标；当用户点击空白区域、完成操作或再次点击顶栏按钮后，自动重新隐藏原生任务栏并恢复 Dock。
3. **拦截单按 `Win` 键呼出启动台（用户已确认）**：
   - 使用低级键盘钩子（`WH_KEYBOARD_LL`）实现精准的单键状态机：
     - **仅当 `LWin` 或 `RWin` 单独按下并松开、期间未触发任何其他按键或鼠标组合操作时**，吞掉开始菜单触发，改为切换显示/隐藏 **Launchpad（启动台）**。
     - **完整放行所有 `Win + 任意键` 组合热键**（`Win+E`、`Win+D`、`Win+L`、`Win+V`、`Win+Shift+S`、`Win+Tab`、`Win+N`、`Win+方向键` 等），确保零破坏 Windows 原生效率体验。
4. **三层防“失联”恢复保障**：
   - **正常退出**：`App.OnExit` 与 `SystemEvents.SessionEnding` 同步撤销 AppBar、卸载键盘钩子并恢复原生任务栏。
   - **独立看门狗进程（`GlassShell.Watchdog`）**：通过 `WaitForSingleObject` 零 CPU 占用阻塞监听主进程句柄；一旦主进程崩溃或被任务管理器强杀，看门狗在 100ms 内自动还原原生任务栏显示并清理残余状态。
   - **命令行急救入口**：支持 `GlassShell.exe --restore-taskbar` 一键恢复。
5. **全屏自动避让与多屏策略（Designer Call）**：
   - 结合 `SHQueryUserNotificationState` 与前景窗口矩形判定（排除桌面 `Progman`/`WorkerW`），检测到全屏游戏或全屏视频时自动平滑隐藏顶栏与 Dock，退出全屏后立刻恢复。
   - v1 聚焦**主显示器**，以 `MonitorContext` 封装屏幕几何与 DPI，方便 v2 扩展至多显示器。

### 5.2 绝对静默式前台应用菜单栏引擎（`MenuEngine` — 用户已确认 1A）

核心铁律：**任何情况下都不得展开或闪烁目标软件自身的原生下拉菜单**。采用异步静默三级管线（独立 MTA 后台线程，切窗立即取消旧任务，单次探测 200ms 超时熔断）：

1. **Tier 1 — 传统 Win32 `GetMenu` 静默读取**：
   - 对目标 HWND 调用 `GetMenu` 递归读取完整菜单树（名称、分隔线、禁用态 `MF_GRAYED`、勾选态 `MF_CHECKED`、快捷键文本与 `wID`），全程 100% 静默、零界面闪烁。
   - 点击子菜单项时，恢复前台窗口焦点并通过 `PostMessage(hwnd, WM_COMMAND, wID, 0)` 直接精准触发命令。
2. **Tier 2 — 静态 UIA 菜单树静默探测（不调用 `Expand`）**：
   - 若 `GetMenu` 为空，通过 `IUIAutomation` 在受控深度内查找 `ControlType.MenuBar`，**仅读取已经静态存在于无障碍树中的顶层项与子菜单项**（严禁调用 `ExpandCollapsePattern.Expand()`）。仅当某菜单具备完整静态子项且支持静默 `InvokePattern` 时才采纳，否则无缝流转至 Tier 3。
3. **Tier 3 — 可扩展高精度内置应用配置表（JSON Profiles）+ 通用兜底菜单**：
   - 针对现代 Windows 高频无标准菜单软件（**Chrome、Edge、Firefox、VS Code、Windows 资源管理器、新版 Win11 记事本、Windows 终端、Office、微信、QQ、Photoshop/常用专业软件**），内置按 macOS 菜单结构精心编排的 JSON 配置文件（文件 / 编辑 / 显示 / 标签页 / 窗口 / 帮助），底层通过精准窗口消息与无冲突快捷键向目标窗口静默派发命令。
   - 配置表支持开源社区通过独立 JSON 文件轻松扩充（面向 GitHub 贡献者极其友好）。
   - 未命中的未知现代应用自动展示干净实用的通用 macOS 菜单（`文件`、`编辑`、`窗口（最小化/最大化/左半屏/右半屏/置顶/关闭）`、`帮助`）。

### 5.3 DXGI 实时液态玻璃渲染引擎（`Glass` — 用户已确认 2A）

为在阶段一直接还原 **macOS Tahoe（26+）Liquid Glass** 真实光学质感，同时解决 WPF 分层窗口与 DWM Acrylic 的冲突：

1. **轻量 DXGI 桌面局部采样管线**：
   - 使用 DXGI `IDXGIOutputDuplication`（配合 Direct3D 11 离屏纹理）捕获桌面画面，仅裁剪更新 **顶栏区域（若开启底色）与 Dock 胶囊矩形区域** 对应的背景纹理；利用 `DesktopDuplication` 的脏矩形机制（Dirty Rects）与按需更新策略（静止桌面几乎 0 GPU 占用，动画/窗口拖动时同步至显示器 60/120Hz 刷新率），将显存与 GPU 开销压到最低。
   - 对自身窗口区域设置 `WDA_EXCLUDEFROMCAPTURE`（Windows 11 原生支持），防止采样器把 GlassShell 自身拍进去产生“无限套娃反馈”！
2. **D3D11 HLSL 液态玻璃着色器**：
   - **多通高斯模糊（Kawase / Dual-Filter Blur）**：高效获得丝滑奶油状背景虚化。
   - **边缘光学折射（Edge Refraction）**：在 Squircle 胶囊边缘一定像素带宽内，按法线方向对采样坐标施加平滑折射偏移（模拟曲面玻璃折射后方壁纸与窗口色彩的效果）。
   - **镜面高光与液态色泽（Specular Rim & Tint）**：顶部与左上缘绘制细腻的 1px 渐变镜面高光描边、微弱色散/提亮层，支持「通透 / 平衡 / 磨砂」三档与浅色/深色主题自适应。
   - **完美抗锯齿 Squircle 裁剪与柔和外投影**：在着色器内用 SDF（Signed Distance Field）直接计算连续曲率 Squircle 抗锯齿边界与多层柔和环境阴影，并输出至 WPF `D3DImage` / 合成层；上层 WPF 透明图层负责渲染图标、文字与高分矢量 UI，**允许悬停放大的 Dock 图标自由冲出玻璃胶囊上边界且不被裁切**。
3. **壁纸明暗自适应**：
   - 监听壁纸变化并采样屏幕顶部 28px 区域平均亮度，自动切换全透明顶栏文字与图标为纯白（配极淡文字阴影）或纯黑，确保在亮色/暗色壁纸上始终清晰。

### 5.4 五大桌面界面组件规范

#### 1. 顶部菜单栏（`MenuBarWindow`）
- **尺寸与形态**：屏幕顶部通栏，高度 **28 DIP**；默认完全通透悬浮在壁纸上方（Tahoe 默认风格），支持在设置中开启「显示菜单栏液态玻璃底色」。
- **左侧区域**：
  - **Win11 Logo 菜单**：关于本机（自绘 macOS 风格简洁本机硬件卡片）、系统设置（GlassShell 设置 + 快捷直达 Windows 设置）、Microsoft Store、最近使用的项目、强制退出（简洁进程结束浮窗）、睡眠、重新启动、关机、锁定屏幕、注销。
  - **当前活动应用名（加粗）**：关于该应用、隐藏窗口、退出（`Alt+F4`）、强制退出。
  - **动态全局菜单**：由 `MenuEngine` 驱动；支持点开某菜单后鼠标横向滑过相邻一级菜单自动无缝切换展开；采用液态玻璃圆角下拉浮层、系统蓝胶囊悬停高亮、不可用项置灰显示、右对齐快捷键提示。
- **右侧区域（Menu Bar Extras）**：
  - 系统托盘临时展开箭头（点击按 5.1 逻辑呼出底部托盘）
  - 输入法指示器（「拼」/「英」，点击可切换键盘布局）
  - 电池图标与百分比（无电池台式机自动隐藏）
  - Wi-Fi / 有线网络状态图标
  - 聚焦搜索放大镜图标
  - **控制中心双滑块图标**
  - **日期与时间**（如 `11月23日 周一 10:03`；**Designer Call**：点击在右下方弹出精致的 Liquid Glass 精简日历卡片，并在卡片内提供一键打开 Windows 原生通知中心 `Win+N` 的按钮，同时屏蔽底部原生任务栏趁机弹起）。

#### 2. 底部程序坞（`DockWindow`）
- **形态与位置**：屏幕底部居中悬浮，距底边 **6 DIP**；容器窗口顶部预留足够透明高度供图标放大冲出与气泡显示，内部由 5.3 的 DXGI 液态玻璃引擎绘制 Squircle 胶囊，宽度随图标数量和放大态平滑伸缩。
- **三段式分区**（半透明 1px 竖线分隔）：
  1. **常驻应用区**：最左端固定为 **此电脑/资源管理器** 与 **启动台**，其后为用户固定应用。
  2. **临时运行应用区**：未固定但已打开的窗口应用自动出现，关闭后平滑移出（可选显示最近 3 个应用）。
  3. **收纳与回收区**：固定常用文件夹（默认预置 **下载** 堆栈，点击以 Liquid Glass 网格浮窗展开最近文件）、最小化窗口缩略图（**Designer Call**：在 `EVENT_SYSTEM_MINIMIZESTART` 时捕获静态快照缓存，与真实 macOS 一致；启动前已最小化的窗口降级显示高清应用图标 + 标题卡片），最右端固定 **回收站**（空/满图标动态切换，右键一键清空）。
- **核心动效与交互**：
  - **高斯曲线波浪放大**：绑定 `CompositionTarget.Rendering` 同步显示器刷新率（60/120Hz），平滑计算指针周边图标缩放与水平推开。
  - **弹簧重力弹跳**：启动未运行应用时图标弹簧弹跳直至主窗口出现；后台窗口闪烁提醒时单次/循环弹跳。
  - **运行指示点**：运行中应用正下方 4px 高亮圆点。
  - **悬停气泡（Tooltip）**：图标上方带向下小尖角的 Liquid Glass 圆角文字标签。
  - **完整拖拽交互**：拖拽重排；拖入 `.exe`/`.lnk` 固定；拖出 Dock 松手伴随消散动画取消固定；拖文件到图标上以该应用打开。
  - **右键菜单**：列出该应用所有打开窗口并切换、新建窗口、在 Dock 中保留/移除、打开文件位置、退出 / 强制退出。
  - **智能自动隐藏**：支持关闭 / 始终自动隐藏 / 智能避让（窗口最大化触底时自动收起，鼠标触底带 macOS 风格防误触延迟后滑出）。
- **图标视觉统一（Icon Harmonizer）**：优先提取 256px Shell 高清图标 / UWP 资源，对形状不规则的传统 Win32 图标提供柔和 Squircle 统一视觉规范选项。

#### 3. 控制中心（`ControlCenterPopup`）
- 点击右上角控制中心图标在下方平滑展开 Liquid Glass Bento 圆角模块卡片（**Designer Call**：严格仅使用公开 WinRT/Win32 API，避免重造整套系统网络/配对设置）：
  - **连接模块**：Wi-Fi 开关（显示当前 SSID + 快捷跳转 Windows Wi-Fi 设置）、蓝牙电源开关（+ 快捷跳转蓝牙设置）、剪贴板/共享快捷入口（触发原生 `Win+V` / 就近共享）。
  - **状态模块**：专注/勿扰快捷入口（跳转 Windows 专注设置或提供 GlassShell 本地静音徽标，不碰未公开 WNF 接口）、外观快捷切换（浅色 / 深色 / 自动）。
  - **亮度滑块**：圆角胶囊滑块（笔记本 WMI + 外接屏 DDC/CI；不支持调节的屏幕自动置灰或隐藏）。
  - **音量滑块**：圆角胶囊滑块 + 动态音量图标 + CoreAudio 音频输出设备快速切换。
  - **正在播放卡片**：WinRT SMTC 实时读取当前媒体封面、歌名、歌手与播放控制按钮。

#### 4. 聚焦搜索（`SpotlightWindow`）
- **触发方式**：全局快捷键（默认 `Alt + Space`，可在设置修改）或点击顶栏放大镜。
- **形态与功能**：居中偏上（约 25% 屏幕高度）Liquid Glass 悬浮搜索胶囊，输入后平滑展开双栏结果面板（左分类列表 + 右详情预览）：
  - **应用搜索**：毫秒级模糊匹配 + 拼音首字母匹配已安装 Win32 与 UWP 应用。
  - **即时计算**：输入算式即时显示大字号结果，回车复制。
  - **系统命令**：锁屏、关机、重启、切换深浅色、清空回收站、打开设置等。
  - **本地文件搜索**：索引桌面/文档/下载目录，并预留可选联动 `Everything` IPC 接口实现全盘瞬搜。
  - **纯键盘操作**：`↑/↓` 切换、`Enter` 打开、`Ctrl+Enter` 打开文件位置、`Esc` 退出。

#### 5. 启动台（`LaunchpadWindow`）
- **触发方式**：单按 `Win` 键（用户已确认）或点击 Dock 启动台图标。
- **形态与功能**：全屏高模糊桌面覆盖层 + 平滑缩放淡入动效；顶部居中圆角搜索框；主体为分页应用图标网格（默认 7×5 自适应），支持滚轮/方向键翻页、底部页码点、拖拽排序与拖合文件夹分组；点击空白处、再次按 `Win` 或按 `Esc` 立即平滑关闭。

#### 6. 极简 macOS 风格设置页（`SettingsWindow`）
严格克制参数数量，只提供 macOS 原生同款核心选项：
- **外观**：浅色 / 深色 / 跟随系统；液态玻璃通透度（通透 / 平衡 / 磨砂）；菜单栏液态玻璃底色开关。
- **程序坞**：图标基础大小；悬停放大开关与放大倍率；自动隐藏模式（关闭 / 始终 / 智能避让）；显示最近打开的应用；图标 Squircle 美化开关。
- **快捷键**：聚焦搜索热键；单按 `Win` 键接管启动台开关（默认开启，可随时关闭还原原生开始菜单）。
- **通用与安全**：开机自启；一键恢复 Windows 原生任务栏；导出诊断日志；关于与版本号。

## 6. 分阶段交付路线（Phased Delivery）

- **阶段一（MVP 日常主力可用版）**：
  - 安装 `.NET 8 SDK` 并搭建 `GlassShell.sln` 工程结构。
  - 交付安全隐藏原生任务栏 + 防弹回状态机 + 独立看门狗恢复 + 顶部 AppBar + 全屏自动避让 + 顶栏托盘临时呼出。
  - 交付 **DXGI 局部桌面采样 + D3D11 HLSL 液态玻璃引擎**（真 Squircle、边缘光学折射、高光描边、柔和阴影、`WDA_EXCLUDEFROMCAPTURE`）。
  - 交付 **顶部菜单栏 + 绝对静默三级前台应用菜单引擎**（Win32 `GetMenu` + 静态 UIA + 高频应用 JSON 配置表 + 通用菜单）+ 精简日历卡片。
  - 交付 **底部 Dock 栏**（常驻/运行应用、高斯放大、弹簧弹跳、气泡、右键菜单、拖拽、回收站、智能自动隐藏）。
- **阶段二（完整 macOS 桌面套件）**：
  - 交付 **单按 `Win` 键接管 + 启动台（Launchpad）**（全屏模糊、搜索、分页、文件夹分组）。
  - 交付 **聚焦搜索（Spotlight）**（应用、拼音首字母、即时计算、系统命令、本地文件索引）。
  - 交付 **控制中心（Control Center）**（Wi-Fi/蓝牙/音量/亮度/WinRT 媒体卡片/`Win+V`）。
  - 交付 Dock 文件夹堆栈（下载网格浮窗）与最小化前静态快照预览。
- **阶段三（细节打磨与 GitHub 开源发布准备）**：
  - 壁纸明暗采样自适应顶栏文字、图标 Squircle 统一美化器、极简设置页完善。
  - 多场景稳定性压测（DPI 缩放变更、锁屏唤醒、资源管理器重启、全屏游戏切出、低功耗静置验证）。
  - 绿色便携版与安装程序打包脚本、开源许可证、README 与应用菜单 JSON 贡献指南。

## 7. 留给实现阶段决定的技术细节（Left to the Builder）

以下实现细节不影响产品边界，由实现规划与编码阶段直接定案：
- 具体 Win32 / COM / Direct3D 11 绑定选型（如 `Vortice.Direct3D11` + `Vortice.DXGI` vs 手写精简 COM Interop，`CsWin32` vs 手写 P/Invoke）。
- CoreAudio 与 DDC/CI 封装库（如 `NAudio` 或轻量级原生 COM 封装）。
- 拼音首字母匹配轻量库或内置汉字首字母映射表实现方式。
- 本地配置文件的精确 JSON Schema、存储路径（默认 `%LocalAppData%\GlassShell\`）及日志框架选型。
- HLSL 着色器具体折射率/模糊半径/高光衰减参数与弹簧/高斯曲线阻尼常数（以视觉贴近 macOS Tahoe 为验收标准）。
